## Keputusan Penting Hasil Brainstorming

- **Single-page (one-pager)** dengan smooth scroll (Lenis), bukan multi-halaman.
- Konten portofolio (Selected Work, stats, dll) **statis/hardcoded**, bukan dari
  database — proyek masih **placeholder**, akan diganti Abdal sendiri nanti.
- Database (Prisma) **hanya** dipakai untuk **visitor counter** (IP di-hash + geo
  negara), bukan untuk konten.
- Form kontak pakai **EmailJS** (client-side, tanpa backend kirim email sendiri),
  didampingi tombol WhatsApp cepat.
- Semua gambar visual (foto profil, thumbnail proyek, ilustrasi hero) adalah
  **placeholder** yang mudah diganti — bukan aset final.
- Wajib **fully responsive**: mobile, tablet, desktop.
