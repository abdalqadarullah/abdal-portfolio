# Portfolio Assets

Letakkan gambar hero visual dan gambar project portfolio di folder ini.

## Nama file yang disarankan

```text
hero-visual.webp
project-alpha.webp
brand-nova.webp
comic-series-episode-01.webp
visual-identity-kit.webp
mobile-app-concept.webp
social-media-kit.webp
```

Website dapat mengakses file melalui path berikut:

```text
/assets/portfolio/nama-file.webp
```

## Rekomendasi format

- Gunakan `WebP` atau `AVIF` untuk gambar final.
- Hero visual: rasio persegi, sekitar `1200 × 1200 px`.
- Project card: rasio `4:3`, sekitar `1200 × 900 px`.
- Gunakan nama file lowercase dengan tanda hubung.
- Hindari spasi dan karakter khusus pada nama file.

Setelah semua gambar tersedia, konfirmasi agar path gambar di `src/data/content.ts` dapat diperbarui dari placeholder ke asset lokal.
